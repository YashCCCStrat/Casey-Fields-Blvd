# Symbology

From github.com/GISsymbology (owner's choice):
- `maki/` – Mapbox Maki icons, 15 px set (from GISsymbology/QGIS-Resources, `all_maki_icons`). **CC0 1.0** (LICENSE.txt).
- `road_signs/` – road sign SVGs (from GISsymbology/QGIS-Resources, `road_signs`). **CC0 1.0** (LICENSE.txt).
- `north_arrows/` – north arrows (from GISsymbology/symbols, `n_arrows`, by Silvio Grosso). **CC BY-SA 2.5** (LICENSE.html).
The geology (CARG, FGDC), seismic microzonation and SICOD collections in GISsymbology/symbols are not used.
Line and area colours follow each plan's own legend.
